# 📚 Books Scraper Python

A beginner-friendly Python web scraping project that extracts book information from [Books to Scrape](https://books.toscrape.com/) and saves it into a structured CSV file.

## 🚀 Features
- Sends HTTP requests using the `requests` library.
- Parses HTML content using `BeautifulSoup`.
- Extracts book titles, prices, and availability status.
- Exports the structured data into a CSV file using `csv.DictWriter`.

## 🛠️ Tech Stack
- Python 3.x
- Requests
- BeautifulSoup4
- CSV Module
